# IDIOM PRACTICE — GitHub Pages 公開手順

800問の英熟語を4択で練習する、静的なWebサイトです。外部サービス・APIキー・ビルド処理は不要です。

## GitHubにアップロードするファイル

以下の構成をリポジトリの最上位（root）に置きます。

```text
（GitHub リポジトリのルート）
├── index.html
├── style.css
├── app.js
├── README.md
├── data/
│   ├── answer-bank-001-800.js
│   ├── quiz-001-100.js
│   ├── quiz-101-200.js
│   ├── quiz-201-300.js
│   ├── quiz-301-400.js
│   ├── quiz-401-500.js
│   ├── quiz-501-600.js
│   ├── quiz-601-700.js
│   └── quiz-701-800.js
└── review/
    └── quiz-***-***-review.csv （管理用。公開に必須ではありません）
```

※ `idiom-practice-site` という外側のフォルダ自体を丸ごとアップロードするのではなく、その**中身**をリポジトリの最上位に配置してください。

## 公開

1. GitHubで新規リポジトリ（例: `idiom-practice`）を作成。公開は Public が簡単です。
2. このZIPを展開し、中のファイルと `data` フォルダを GitHub リポジトリの最上位にアップロードしてコミットします。
3. GitHubリポジトリの **Settings → Pages** を開き、**Build and deployment** の **Source = Deploy from a branch** を選択。
4. **Branch = main / Folder = /(root)** を選択し **Save**。
5. 公開されたURLにアクセスします（例: `https://ユーザー名.github.io/idiom-practice/`）。反映まで若干時間がかかる場合があります。

## サイトの機能

- No.1–100からNo.701–800まで、100問区切り8範囲から選択
- ランダム／番号順、20/50/70/100問
- 各問4択、タップで即時正誤判定・正答表示
- 進捗バー、正解数、終了時の正答率
- 間違えた問題だけを再出題／同じ設定で再挑戦
- 学習中のHOMEボタン（確認ダイアログあり）
- 同一学習セッション内で同じ熟語は繰り返し出題されない
- 正答の表示位置は出題のたびにランダム
- スマートフォン・Chromebook・PC対応
- PCでは数字キー1〜4で解答、解答後Enterで次の問題に進めます

## データについて・出題品質の注意

- 元データ：ユーザー提供『熟語1-800.pdf』『解答1-800.pdf』。
- 日本語訳は解答PDFの記載を保持しています。
- 各問の誤答3つは800件の日本語訳から事前に作成した候補です。誤答候補のIDは問題ファイルの `distractorIds` にあります。
- **毎回変わるのは選択肢の表示順です。誤答候補自体は固定です。**
- 機械的な検査（800件の連続性、正答・誤答の文字列重複）は行っていますが、すべての問題の意味上の複数正解がないかを人手で保証したものではありません。公開前に `review` フォルダ内のCSVで確認してください。
- 同義の日本語訳が元PDF内に複数ある場合があります。誤答と正答に同じ文字列が並ばないようにしていますが、厳密な意味での同義性は別途確認が必要です。

## データを変更したい場合

- `data/quiz-XXX-YYY.js` の `distractorIds` をほかの解答番号に差し替えると、選択肢を変更できます。
- `data/answer-bank-001-800.js` の日本語訳を編集すると、その訳が表示されるすべての問題に反映されます。
- `data/quiz-XXX-YYY.js` の `idiom` を修正すると、問題本文を変更できます。
- 数字IDは1〜800を維持してください。
